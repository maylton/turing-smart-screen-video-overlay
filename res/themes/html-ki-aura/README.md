# Aura de Ki

Original 480×480 HTML theme with a native video background (Turing Smart
Screen Rev. C 2.1"/2.8"). The animated background is built into
`html-ki-aura.mp4`; the readouts are overlays fed by the sensor snapshot.
Fonts are bundled latin woff2 subsets under the SIL Open Font License 1.1
(see `fonts/`).
