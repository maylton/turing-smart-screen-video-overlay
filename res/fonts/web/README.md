# Fonts for HTML themes

Web fonts offered by the HTML theme editor (the TTF folders next to this one
belong to the YAML themes). Each one comes from Google Fonts
(latin subset, woff2) and is licensed under the SIL Open Font License 1.1;
the license is next to the font files.

When a theme uses one of them, the editor copies the font files and the
license into the theme's `fonts/` folder, so exported themes stay
self-contained. `catalog.json` lists the families, weights and files.
